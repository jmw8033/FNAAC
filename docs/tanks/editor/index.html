    How to edit and publish

    Paint or erase terrain by dragging. Select a tank and drag to move it; use the inspector to change its type or cell. Right-click erases an enemy or obstacle. Player starts and the outer wall cannot be erased. Arrow keys move the canvas cursor; Space applies the current tool. Ctrl/Cmd+Z undoes; Ctrl/Cmd+Y redoes.

    Test level opens a one-mission run in a new tab. Play campaign starts at the first mission. Keep the editor and game on the same website origin. Local file playback can have browser storage restrictions; a local HTTP server is more reliable.

    Export JSON saves an editable backup. Export campaign.js creates the file to replace at tanks/campaign.js in your GitHub Pages publishing folder. After pushing it, players can choose Published campaign. This editor does not push to GitHub. Imported packs are validated; unreachable enemies generate a warning because firing across pits can be intentional.
